# Diagrams

The animated architecture figures for this series live on the article pages
themselves, not as static images in this repo — see:

- https://esbenthomsen.com/writing/cheap-compute-real-engineering
- https://esbenthomsen.com/writing/the-lakehouse-is-not-the-runtime
- https://esbenthomsen.com/writing/where-i-stop-using-python

Each figure traces a real state machine (queued → scheduled → running →
committed → ...) rather than a static export, so keeping them live on the
site avoids the diagrams drifting out of sync with the code in this repo.
